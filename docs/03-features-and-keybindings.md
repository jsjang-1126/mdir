# 기능 및 단축키 레퍼런스

## 실행

```bash
mdir              # 현재 디렉터리에서 시작 (양쪽 패널 동일 경로)
mdir ~/Downloads  # 지정 경로에서 시작
mdir --help
```

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 왼쪽 패널 | 파일/폴더 목록 (패널 1) |
| 오른쪽 패널 | 파일/폴더 목록 (패널 2) |
| 미리보기 | 선택 파일 텍스트 미리보기 (`p`로 숨김/표시) |
| 상태바 | 경로, 선택 항목, 크기, **수정일시(초)**, 권한 |
| 도움말 줄 | 주요 단축키 요약 |
| Footer | Textual 기본 바인딩 표시 |

**활성 패널** = 연두색 굵은 테두리. `Tab`으로 전환.

## 단축키 전체

### 탐색

| 키 | 동작 |
|----|------|
| `Tab` | 활성 패널 전환 |
| `↑` `↓` / `j` `k` | 목록 이동 |
| `Enter` | 폴더 진입 / 파일 `xdg-open` |
| `u` / `Backspace` | 상위 폴더 |
| `PageUp` `PageDown` | 페이지 스크롤 |
| `Home` `End` | 목록 처음/끝 |

### 파일 작업

| 키 | 동작 |
|----|------|
| `F5` | 활성 패널 선택 항목 → **반대 패널 경로**로 복사 |
| `F6` | 이동 (대상: 반대 패널) |
| `F7` | 새 폴더 생성 |
| `F8` | 삭제 (확인 모달) |
| `F2` | 이름 변경 |
| `/` | 현재 패널 파일명 필터 |
| `r` | 양쪽 패널 새로고침 |

### 북마크

| 키 | 동작 |
|----|------|
| `b` | 북마크 메뉴 |
| `g` | 저장된 북마크로 이동 |

**북마크 메뉴 (`b`):**

| 선택 | 동작 |
|------|------|
| `a` / Add | 현재 폴더를 북마크로 등록 (이름 입력) |
| `d` / Delete | 북마크 삭제 |
| `c` / Cancel | 취소 |

**북마크 추가 2단계:**
1. `b` → Add 선택 (`Enter` 또는 `a`)
2. 이름 입력 → `Enter` 저장 / `Esc` 취소

**북마크 사용:**
- `g` → 목록에서 선택 → 해당 경로로 **활성 패널** 이동

**저장 파일:** `~/.config/mdir/bookmarks.json`

### 편집·미리보기

| 키 | 동작 |
|----|------|
| `p` | 미리보기 패널 토글 |
| `v` | 선택 **텍스트 파일**을 vim으로 열기 (종료 후 탐색기 복귀) |
| `n` | nano로 열기 |

텍스트 판별: 확장자 목록 + 바이너리(null 바이트) 검사.

### 기타

| 키 | 동작 |
|----|------|
| `q` | 종료 |

## 상태바 정보 형식

```
mdir v0.1.0  |  /path/to/dir  |  📄 file.txt  1.2 KB  2026-06-18 14:32:05  -rw-r--r--  |  메시지
```

패널 `Modified` 컬럼은 좁을 수 있어, **초 단위 수정일시는 상태바**에 표시.

## 외부 의존

| 기능 | 필요 |
|------|------|
| 파일 열기 (Enter) | `xdg-open` (Linux 데스크톱) |
| vim / nano | 각각 설치 (`apt install vim nano`) |
| SSH 서버 배포 | `rsync`, `ssh`, 원격 `python3` |

서버(헤드리스)에서는 `xdg-open` 없이도 탐색·복사·vim/nano는 동작.
